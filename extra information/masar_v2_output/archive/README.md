# Historical runs

- `capacity_trials/`: nine earlier population and capacity scenarios, each with saved inputs and results.
- `section_optimization/`: seventeen earlier attempts to reduce section counts; some contain only inputs.
- `five_majors_from_sources/`: the separate run folder from which the current main timetable was promoted.
- `before_five_majors_from_sources/`: the main timetable and reports before that promotion.
- Other `before_*` folders are older project snapshots.

These folders are retained for history. The active timetable is one level up in `masar_v2_output/timetable.csv`.
