# Timetable run details

Each run is written to its own folder in `runs/` (not tracked by git; the newest 20 are kept).
A run replaces the files below **only if its timetable passed independent validation**. They are
then replaced together, so they always describe the same run. `PUBLISHED_RUN.txt` names that run.
A run without a validated timetable stays in `runs/` for diagnosis, leaves these files unchanged,
and exits with status 2.

- `../../masar_v2_output/timetable.csv`: active five-major timetable. University-required and university-elective courses are excluded.
- `by_major/`: five views of the active timetable, regenerated by every published run; shared courses appear in each eligible major's file.
- `result.json`: solver status, validation, and section details.
- `input_snapshot.json`: the exact scheduling input associated with `result.json`.
- `archive/`: older scenarios and experiments, not the current timetable.

The active curriculum is in `course_requirements/`. The editable course switches and student totals are in `settings/`.
